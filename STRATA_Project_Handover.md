## 🏛️ System Architecture Overview
The STRATA Vector Suite is a high-fidelity, interactive financial forecasting application built for non-accounting users. Unlike traditional forecasting platforms that rely on brittle, cell-dependent spreadsheet models, STRATA operates as a self-contained, transaction-voucher engine.

The entire application footprint has been consolidated into a clean, modern two-tier structure, removing all historical dependencies on external mathematical modules, separate array builders, or complex HTML compilers.
